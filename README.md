# 🪙 Minimal Crowdfunding DApp

## 📄 Project Description

This is a lightweight smart contract for a decentralized crowdfunding platform built on Ethereum. It allows users to contribute ETH toward a funding goal, and supports both fund withdrawal by the campaign owner and refunds if the goal is not met.

## 🎯 Project Vision

The vision behind this project is to provide a minimal and gas-efficient crowdfunding mechanism for small-scale projects, creators, or charitable causes using decentralized technology.

## 🔑 Key Features

- **Owner-controlled goal and duration setup**
- **Secure contribution tracking using mappings**
- **Automatic refund to contributors if goal isn't met**
- **Single withdrawal function for fund disbursement**

## 🚀 Future Scope

- Add support for multiple campaigns.
- Include milestone-based fund release.
- Integrate frontend for real-time progress tracking.
- Extend to accept ERC20 tokens as contributions.
- Add KYC and verification layers for campaign owners.
